# Daily Task Assessment - Day 12

\<h3>SQL Data Types, Constraints, Keys, and Basic SQL Commands\</h3>

\<p>
Today I learned about \<b>SQL data types, constraints, database keys, and basic SQL commands\</b> used to create tables, insert records, update and delete data, and modify existing table structures.
\</p>

\<br>

\<h3>1. SQL Data Types\</h3>

\<p>
Learned about different SQL data types, including \<b>INTEGER, VARCHAR, TEXT, DATE, BOOLEAN, and TIMESTAMP\</b>, and how to choose appropriate data types for storing different kinds of information.
\</p>

\<h3>2. SQL Constraints\</h3>

\<p>
Learned about SQL constraints such as \<b>NOT NULL, UNIQUE, CHECK, and DEFAULT\</b>, which help maintain data accuracy and integrity.
\</p>

\<h3>3. Types of Database Keys\</h3>

\<p> Learned about different types of database keys, including \<b>Primary Key, Foreign Key, Candidate Key, Super Key, Alternate Key, surrogate key, and Composite Key\</b>, and how they identify records and establish relationships between tables. \</p>

\<h3>4. CREATE and INSERT Commands\</h3>

\<p>
Learned how to use the \<b>CREATE\</b> command to create databases and tables, and the \<b>INSERT\</b> command to add new records to tables.
\</p>

\<h3>5. UPDATE and DELETE Commands\</h3>

\<p>
Learned how to use the \<b>UPDATE\</b> command to modify existing records and the \<b>DELETE\</b> command to remove records from a table.
\</p>

\<h3>6. ALTER Command\</h3>

\<p>
Learned how to use the \<b>ALTER\</b> command to modify an existing table structure, including adding, modifying, and removing columns and constraints.
\</p>

\<h3>Conclusion\</h3>

\<p>
Gained practical knowledge of SQL data types, constraints, database keys, and essential SQL commands for creating tables, managing records, maintaining data integrity, and modifying database structures.
\</p>

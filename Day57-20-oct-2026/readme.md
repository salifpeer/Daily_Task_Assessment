<p>
Learned about the following Deep Learning architectures:
</p>

<ul>
<li><b>ANN (Artificial Neural Network):</b> Used for learning patterns in structured data and making predictions.</li>
<li><b>CNN (Convolutional Neural Network):</b> Commonly used for image processing and computer vision tasks.</li>
<li><b>RNN (Recurrent Neural Network):</b> Designed to process sequential data, such as text and time series.</li>
<li><b>LSTM (Long Short-Term Memory):</b> A type of RNN designed to learn long-term dependencies in sequential data.</li>
</ul>

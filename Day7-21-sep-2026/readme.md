<h3>Streamlit and Patient Management System</h3>
<p>
Today I learned the basics of <b>Streamlit</b> and understood how it can be used to create interactive web applications using Python. I also developed the Streamlit frontend for my <b>Patient Management System</b> and connected it with my FastAPI backend.
</p>

<br>

<h3>1. Streamlit</h3>

<p>
Learned the basic concepts of Streamlit and how Streamlit widgets are used to create interactive applications. I worked with text inputs, number inputs, buttons, select boxes, file uploaders, and displaying data.
</p>

<p>
I also learned about <b>Streamlit sessions and Session State</b>. I understood how Streamlit reruns the script when a user interacts with a widget and how Session State can be used to maintain application state across reruns.
</p>

<h3>2. Streamlit and FastAPI Integration</h3>

<p>
Developed a Streamlit frontend for my <b>Patient Management System</b> and connected it with the FastAPI backend using HTTP requests. I worked with GET and POST requests to retrieve and add patient information.
</p>

<h3>3. Patient Management System</h3>
<p>
Worked on the frontend for adding and displaying patient details such as patient ID, name, height, weight, and gender. The Streamlit frontend communicates with the FastAPI backend, which handles the patient data.
</p>

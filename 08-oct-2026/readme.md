# Daily Task Assessment - Day 11

<h3>Functional Dependency, Database Normalization, Anomalies, and SQL Commands</h3>

<p>
Today I learned about <b>functional dependencies</b>, insertion, deletion, and updation anomalies in SQL, database normalization, and the different categories of SQL commands, including DDL, DML, TCL, and DCL.
</p>

<br>

<h3>1. Functional Dependency</h3>

<p>
Learned about functional dependencies in databases and how one attribute or a set of attributes can determine the values of other attributes.
</p>

<h3>2. Insertion, Deletion, and Updation Anomalies</h3>

<p>
Learned about database anomalies, including <b>insertion anomalies, deletion anomalies, and updation anomalies</b>, and how redundant data can cause problems in database management.
</p>

<h3>3. Database Normalization</h3>

<p>
Learned about database normalization, its importance in reducing data redundancy and improving data integrity, and the basic normal forms: <b>1NF, 2NF, and 3NF</b>.
</p>

<h3>4. Overview of SQL Commands</h3>

<p>
Learned about the major categories of SQL commands:
</p>

<ul>
<li><b>DDL (Data Definition Language):</b> CREATE, ALTER, DROP, TRUNCATE.</li>
<li><b>DML (Data Manipulation Language):</b> INSERT, UPDATE, DELETE.</li>
<li><b>TCL (Transaction Control Language):</b> COMMIT, ROLLBACK, SAVEPOINT.</li>
<li><b>DCL (Data Control Language):</b> GRANT, REVOKE.</li>
</ul>

<h3>Conclusion</h3>

<p>
Gained a basic understanding of functional dependencies, database anomalies, normalization techniques, and the different categories of SQL commands used to define, manipulate, and control databases.
</p>

# Daily Task Assessment - Day 15

<h3>Stored Procedures, Triggers, Transactions, ACID Properties, and TCL Commands in PostgreSQL</h3>

<p>
Today I learned about <b>stored procedures and triggers</b> in PostgreSQL, along with database transactions, the <b>ACID properties</b>, and Transaction Control Language (TCL) commands used to manage database transactions.
</p>

<br>

<h3>1. Stored Procedures in PostgreSQL</h3>

<p>
Learned about stored procedures, their purpose, and how to create and execute reusable blocks of SQL and procedural code to perform database operations.
</p>

<h3>2. Triggers in PostgreSQL</h3>

<p>
Learned about database triggers, how they execute automatically in response to events such as <b>INSERT, UPDATE, and DELETE</b>, and how they help automate database operations and maintain data integrity.
</p>

<h3>3. Database Transactions</h3>

<p>
Learned about database transactions, which group multiple operations into a single logical unit to ensure that related database changes are handled consistently.
</p>

<h3>4. ACID Properties</h3>

<p>
Studied the four fundamental ACID properties of database transactions: <b>Atomicity, Consistency, Isolation, and Durability</b>, which help ensure reliable and consistent database operations.
</p>

<h3>5. TCL Commands in PostgreSQL</h3>

<p>
Learned about Transaction Control Language (TCL) commands, including <b>BEGIN, COMMIT, ROLLBACK, and SAVEPOINT</b>, which are used to start transactions, save changes, undo changes, and create points to which a transaction can be rolled back.
</p>

<h3>Conclusion</h3>

<p>
Gained a basic understanding of stored procedures, triggers, database transactions, ACID properties, and TCL commands in PostgreSQL for automating operations and maintaining database reliability and consistency.
</p>

# Daily Task Assessment - Day 14

<h3>Subqueries and Indexes in SQL</h3>

<p>
Today I learned about <b>subqueries in SQL</b>, their different types based on results, position, and execution, along with <b>database indexes</b> and the differences between clustered and non-clustered indexes.
</p>

<br>

<h3>1. Introduction to Subqueries</h3>

<p>
Learned about subqueries, which are SQL queries nested inside another query, and how they help retrieve data and perform complex database operations.
</p>

<h3>2. Types of Subqueries Based on Results</h3>

<p>
Learned about <b>scalar subqueries</b>, which return a single value; <b>row subqueries</b>, which return a single row; and <b>table subqueries</b>, which return multiple rows and columns.
</p>

<h3>3. Types of Subqueries Based on Position</h3>

<p>
Learned how subqueries can be used in different parts of SQL statements, including the <b>SELECT, WHERE, FROM, and JOIN</b> clauses.
</p>

<h3>4. Types of Subqueries Based on Working</h3>

<p>
Learned about <b>correlated and non-correlated subqueries</b>. Non-correlated subqueries operate independently of the outer query, while correlated subqueries refer to columns from the outer query.
</p>

<h3>5. Introduction to Database Indexes</h3>

<p>
Learned about database indexes, how they help improve data retrieval performance, and how they can reduce the need to scan every row in a table.
</p>

<h3>6. Types of Indexes</h3>

<p>
Learned about <b>clustered and non-clustered indexes</b>, including how they organize or reference table data and how indexes can improve query performance.
</p>

<h3>Conclusion</h3>

<p>
Gained a basic understanding of subqueries and their classifications, correlated and non-correlated queries, and database indexes and their role in improving SQL query performance.
</p>

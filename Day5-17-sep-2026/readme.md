<h1>Daily Task Assessment - Day 4</h1>

<h3>FastAPI CRUD Operations in Python</h3>

<p>
Today I learned more about CRUD operations in FastAPI and understood how APIs are used to add, read, update, and delete data. I also worked with JSON data and learned how different HTTP methods are used to perform these operations.
</p>

<br>

<h3>1. POST Operation</h3>

<p>
Learned how the <b>POST</b> method is used to add new data through an API. I understood how data is received from a request and stored in the JSON file.
</p>

<h3>2. PUT Operation</h3>

<p>
Learned how the <b>PUT</b> method is used to edit or update existing data. I learned how to find a particular patient using its ID and update the required information.
</p>

<h3>3. DELETE Operation</h3>

<p>
Learned how the <b>DELETE</b> method is used to remove a particular record from the data. I also learned how to search for a patient by ID and delete the corresponding dictionary from a list of dictionaries.
</p>

<h3>4. Working with JSON Data</h3>

<p>
Learned how JSON files can be used to store data and how FastAPI can read, modify, and save the data while performing CRUD operations.
</p>

<h3>5. Overall Learning</h3>

<p>
Today I understood the complete flow of CRUD operations in FastAPI:
</p>

<p>
<b>POST</b> → Create data<br>
<b>GET</b> → Read data<br>
<b>PUT</b> → Update data<br>
<b>DELETE</b> → Delete data
</p>

<p>
I also understood how API endpoints, request data, JSON files, and Python code work together to build a basic CRUD API.
</p>

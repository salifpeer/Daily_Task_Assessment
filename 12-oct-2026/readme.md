# Daily Task Assessment - Day 13

<h3>SQL SELECT Statement, Functions, Joins, and Views</h3>

<p>
Today I learned about the <b>SELECT statement</b> and its clauses, different types of SQL functions, SQL joins, and views. I also practiced queries to retrieve, filter, group, sort, and analyze data from databases.
</p>

<br>

<h3>1. SELECT Statement and Its Clauses</h3>

<p>
Learned about the <b>SELECT, FROM, WHERE, GROUP BY, ORDER BY, LIMIT, and OFFSET</b> clauses and how they are used to retrieve, filter, group, sort, and control query results.
</p>

<h3>2. Aggregate Functions</h3>

<p>
Learned about aggregate functions such as <b>COUNT(), SUM(), AVG(), MIN(), and MAX()</b>, which perform calculations on multiple rows and return summarized results.
</p>

<h3>3. String Functions</h3>

<p>
Learned about string functions such as <b>UPPER(), LOWER(), LENGTH(), CONCAT(), and SUBSTRING()</b>, which are used to manipulate and process text data.
</p>

<h3>4. Date and Time Functions</h3>

<p>
Learned about SQL date and time functions for retrieving the current date and time, extracting date components, and performing calculations involving dates and timestamps.
</p>

<h3>5. Window Functions</h3>

<p>
Learned about window functions such as <b>ROW_NUMBER(), RANK(), DENSE_RANK(), and SUM() OVER()</b>, which perform calculations across related rows while preserving individual records.
</p>

<h3>6. Joins in SQL</h3>

<p>
Learned about SQL joins and how they combine data from multiple tables using related columns. Studied the main types of joins, including <b>INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN</b>.
</p>

<h3>7. Views in SQL</h3>

<p>
Learned about SQL views, how to create and retrieve data from views using <b>CREATE VIEW</b> and <b>SELECT</b>, and how views simplify complex queries and provide controlled access to selected data.
</p>

<h3>Conclusion</h3>

<p>
Gained practical knowledge of SQL SELECT clauses, aggregate and string functions, date and time functions, window functions, joins, and views for retrieving, combining, organizing, and analyzing database information.
</p>

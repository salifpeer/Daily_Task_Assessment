<h3>2. Object-Oriented Programming in Python</h3>

<p>
Learned the important concepts of <b>Object-Oriented Programming (OOP)</b> in Python. I understood how classes and objects are created and how different OOP concepts are used to organize and reuse code.
</p>

<p>
The main concepts covered were:
</p>

<p>
<b>Classes and Objects</b> – Learned how classes are used as blueprints and objects are created from classes.
</p>

<p>
<b>Constructors</b> – Learned about the <b>__init__()</b> method and how it is used to initialize object attributes.
</p>

<p>
<b>Inheritance</b> – Learned how a child class can inherit properties and methods from a parent class.
</p>

<p>
<b>Types of Inheritance</b> – Learned about single, multiple, multilevel, hierarchical, and hybrid inheritance.
</p>

<p>
<b>Method Resolution Order (MRO)</b> – Learned how Python determines the order in which methods are searched when multiple classes are involved.
</p>

<p>
<b>Method Overriding</b> – Learned how a child class can provide its own implementation of a method inherited from the parent class.
</p>

<p>
<b>Method Overloading</b> – Learned how Python handles multiple arguments using techniques such as default arguments and variable-length arguments.
</p>

<p>
<b>Encapsulation</b> – Learned how data and methods can be grouped inside a class and how access to data can be controlled.
</p>

<p>
<b>Polymorphism</b> – Learned how the same method or operation can behave differently depending on the object being used.
</p>

<p>
<b>Abstraction</b> – Learned how unnecessary implementation details can be hidden and only the required functionality can be exposed.
</p>
